## 使用提醒

这批图片适合先用于产品测试和内容验证。正式长期商业使用前，建议逐步替换为：
- 自己实地拍摄图片
- 用户授权投稿图片
- 景区官方授权图片
- 明确可商用授权图片

导入路径：
后台登录后进入 `/admin/import`，同时上传本目录下 3 个 CSV 文件，先校验，再导入。
