# 如何确认地点经纬度

导入地点前，必须确认入口经纬度。

## 推荐方式一：高德地图

1. 打开高德地图网页版或手机高德地图。
2. 搜索地点，例如：`木兰天池景区`。
3. 确认搜索结果是景区主入口或游客中心，不要选到附近村庄。
4. 点击分享或复制链接。
5. 把链接发给我，我可以帮你提取经纬度。

## 推荐方式二：百度地图

1. 打开百度地图。
2. 搜索地点名称。
3. 确认入口位置。
4. 复制分享链接。
5. 把链接发给我，我帮你整理成 CSV。

## 重要原则

不要用“城市中心点”代替景区位置。

比如：

- 后官湖湿地公园不能用武汉市中心经纬度。
- 清凉寨不能只用黄陂区经纬度。
- 木兰天池要用景区入口或游客中心位置。

## 发给我的格式

你可以这样发：

```text
地点：木兰天池
地图链接：粘贴高德或百度分享链接
图片URL：粘贴真实图片地址
```

我收到后会帮你生成正式的：

- `spots.csv`
- `facilities.csv`
- `photos.csv`
