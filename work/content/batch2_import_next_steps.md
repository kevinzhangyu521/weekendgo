# 第二批地点导入下一步

本批地点：

1. 后官湖湿地公园
2. 清凉寨
3. 木兰天池

## 当前结论

这 3 个地点现在先不要直接导入。

原因：

- 后官湖和木兰天池已有真实图片线索，但经纬度还需要确认具体入口。
- 清凉寨还缺可靠真实图片 URL 和入口经纬度。
- 导航会影响真实家庭出行，不能用大概位置。

## 你需要补充的信息

每个地点至少补：

- 高德地图或百度地图里的准确入口位置
- 纬度 lat
- 经度 lng
- 真实图片 URL

## 可以先导入吗？

不建议。

因为现在前台已经隐藏“图片待补充”的地点。如果没有真实图片，即使导入也不会显示给用户。

## 推荐处理顺序

1. 先补木兰天池真实入口经纬度。
2. 再补后官湖湿地公园入口经纬度。
3. 最后补清凉寨图片和经纬度。

## 图片规则

可以使用：

- 自己拍摄图片
- 用户授权图片
- 景区官方授权图片
- Wikimedia Commons 可公开访问图片

不要使用：

- AI 图
- 小红书/抖音截图
- 未授权商用图片
- 室内植物图
