# 栖美地推广测试包

这个目录用于存放正式推广前的种子测试和内容运营材料。

建议执行顺序：

1. `promotion_next_10_days.md`
   - 10 天实施节奏
   - 适合每天照着推进

2. `seed_user_test_tasks.md`
   - 发给测试组织者看
   - 用来指导 10-20 个真实家庭完成测试

3. `seed_user_feedback_form.csv`
   - 用户反馈记录表
   - 可以导入 Excel、腾讯文档、飞书表格

4. `wuhan_seed_social_content.md`
   - 小红书、抖音、朋友圈种子文案
   - 先小范围发布，不建议一开始投广告

当前推广阶段：
- 可以开始小范围种子测试
- 暂不建议大规模投流

正式推广前最低门槛：
- TOP10 满 10 个有效地点
- 核心地点有真实图片
- 手机端立即导航稳定
- 登录、收藏、加入计划无阻断
- 至少 10 个真实家庭完成测试
