# 栖美地微信小程序规划

## 阶段目标

先复用现有 Supabase 后端和目的地内容，做一个轻量微信小程序 MVP，让用户可以在微信内完成浏览、收藏、计划和投稿。

## MVP 页面

1. 首页
   - 本周末推荐
   - 四个场景入口：露营、溯溪、徒步、野餐
   - 为你推荐

2. 目的地列表
   - 场景筛选
   - 距离筛选
   - 停车/厕所筛选

3. 目的地详情
   - 图片、位置、省市、适合年龄
   - 设施、安全提示
   - 收藏
   - 加入计划
   - 调起微信位置/高德导航

4. 我的计划
   - 创建周末计划
   - 增删目的地
   - 分享计划

5. 添加推荐地点
   - 上传图片
   - 填写地点、省份、城市、地址、场景、说明
   - 提交审核

6. 我的
   - 登录
   - 我的收藏
   - 我的投稿
   - 我的资料

## 技术路线

- 前端：微信小程序原生或 Taro
- 后端：继续使用 Supabase
- 图片：继续使用 Supabase Storage
- 地图：微信地图组件 + 高德/腾讯位置能力
- 管理后台：继续使用现有网页版后台

## 不建议第一版做的功能

- 社区评论
- 积分体系
- 复杂推荐算法
- 商业广告位
- 多城市大规模运营

这些功能等真实用户量起来之后再做。

## 预计成本

- 小程序 MVP：3万-8万元
- 体验较完整版本：8万-15万元
- 如果加复杂推荐、活动、支付、内容运营后台：15万-30万元以上

## 上线准备

- 微信小程序账号
- 企业主体或个体工商户主体
- 域名备案
- 隐私政策
- 用户协议
- 内容审核规则
- 图片上传审核策略

## 推荐节奏

1. 当前阶段：优化移动网页 + PWA
2. 第 2 阶段：用社媒带流量，验证用户留存和投稿意愿
3. 第 3 阶段：做微信小程序 MVP
4. 第 4 阶段：根据用户量决定是否做独立 App
