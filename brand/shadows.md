# Shadows

栖美地只使用轻阴影。

阴影用于建立层级，不用于制造强烈装饰感。

## Allowed Shadows

### Soft

```css
box-shadow: 0 8px 24px rgba(31, 41, 55, 0.08);
```

Usage:

- Small cards
- Dropdowns
- Feedback panels
- Lightweight floating elements

### Medium

```css
box-shadow: 0 16px 40px rgba(31, 41, 55, 0.12);
```

Usage:

- Featured cards
- Modals
- Important elevated content

## Forbidden

- Heavy black shadows
- Multiple stacked decorative shadows
- Neon shadows
- Shadows that make cards look like ads or game UI

## Interaction

Hover can increase shadow slightly, but should remain calm.
