# Qimeide Brand Kit

This folder is the first brand foundation for 栖美地 (Qimeide).

It defines the shared visual and language rules for:

- Website
- Social content
- App
- Mini program
- Video covers
- Offline brand materials

## Brand

Chinese name: 栖美地

English name: Qimeide

Positioning: Help families decide faster and more confidently where to go this weekend.

Mission: Help families leave more time for being together.

Vision: Become the most trusted weekend decision brand for families in China.

## Usage Rules

All future design work should follow this Brand Kit before creating new UI, marketing content, social templates, or app screens.

Do not add new brand colors, icon styles, shadows, or voice patterns without updating this Brand Kit first.

## Files

- `brand-values.md`: Core values
- `brand-voice.md`: Writing tone and forbidden language
- `colors.md`: Brand color system
- `typography.md`: Type scale and font guidance
- `spacing.md`: Spacing scale
- `radius.md`: Radius rules
- `shadows.md`: Shadow rules
- `icon-style.md`: Icon style rules
- `photography.md`: Photography direction
