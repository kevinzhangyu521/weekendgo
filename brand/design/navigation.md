# Navigation

Navigation should be simple and confidence-building.

## Top Navigation

Principles:

- 简洁
- 固定高度
- Clear priority
- Few links
- Easy to scan

## Height

Recommended desktop header height:

```css
height: 72px;
```

Mobile header can be more compact, but should preserve clear logo and menu access.

## Scroll Behavior

On scroll:

- Use subtle shadow or border
- Keep background readable
- Avoid dramatic glass effects

## Menu Structure

Navigation should expose only high-frequency paths.

Prefer:

- 发现
- 地图
- 投稿
- 登录 / 头像

## Do Not

- Do not use complex menus.
- Do not show too many links in the header.
- Do not mix user actions and admin actions in the same visual group.
- Do not make navigation look like an admin toolbar.
- Do not use heavy glassmorphism.

## Role-Based Navigation

User and admin navigation must stay clearly separated.

Visual design should support role clarity without adding noise.
