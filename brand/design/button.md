# Button

Buttons should be clear, calm, and easy to tap.

## Button Types

### Primary

Usage:

- Main action
- Search
- Submit
- Save
- Confirm

Style:

- Background: Primary Green `#2E7D32`
- Hover: Primary Hover `#256628`
- Text: White

### Secondary

Usage:

- View details
- Secondary navigation
- Non-destructive supporting actions

Style:

- Background: White
- Border: `#E5E7EB`
- Text: `#1F2937`

### Ghost

Usage:

- Low-emphasis text action
- Inline utility action

Style:

- Background: Transparent
- Text: Primary or Text Primary

### Danger

Usage:

- Delete
- Remove
- Reject

Style:

- Background or text: Danger `#EF4444`
- Use carefully and only for destructive actions.

## Sizing

| Size | Height | Horizontal Padding |
| --- | ---: | ---: |
| Standard | 44px | 16px - 20px |
| Large | 48px | 20px - 24px |
| Compact | 36px | 12px - 16px |

## Radius

Button radius: 12px

## States

Hover:

- Slight color change
- No dramatic movement

Loading:

- Disable repeated click
- Show clear loading text or spinner

Disabled:

- Lower contrast
- Cursor should indicate unavailable state

## Do Not

- Do not make every button green.
- Do not use oversized buttons as decoration.
- Do not hide loading state.
- Do not use red for non-danger actions.
