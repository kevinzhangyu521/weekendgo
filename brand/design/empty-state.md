# Empty State

Empty states should be short, helpful, and calm.

## Structure

Use:

1. Illustration
2. One sentence
3. One button

Do not use long explanations.

## Tone

Empty state text should be friendly and practical.

Prefer:

> 暂无推荐内容

> 还没有家庭故事

> 你还没有提交过反馈

Avoid:

> 数据为空，请联系管理员

> API 暂无返回数据

> 暂无 records

## Illustration

Illustrations should follow the brand illustration style:

- Flat
- Linear
- Natural
- Soft

## Action

Only add a button when there is a useful next step.

Examples:

- 添加地点
- 去发现
- 返回首页

## Do Not

- Do not show technical errors.
- Do not blame the user.
- Do not create long instructional paragraphs.
- Do not use sad or alarming visuals.
