# Tag

Tags help users quickly understand scenarios, audience, and conditions.

## Style

- Shape: capsule
- Radius: fully rounded
- Font size: small
- Weight: medium or bold
- Background: soft neutral or soft brand color

## Usage

Use tags for:

- 露营
- 玩水
- 公园
- 亲子
- 徒步
- 野餐
- 适合低龄
- 轻松路线

## Color Rules

- Use a limited set of soft colors.
- Avoid rainbow-like tag groups.
- Similar meanings should use consistent color.
- Do not use saturated colors for every tag.

## Density

Homepage cards:

- Show up to 2 tags.

Detail pages:

- Can show more tags if they help decision-making.

## Do Not

- Do not use tags for every database field.
- Do not repeat information already shown nearby.
- Do not show tags such as "0", "null", "undefined", or raw field names.
- Do not use tags as decoration only.
