# Brand Values

## 1. 真实

没有真实数据宁可不推荐。

栖美地不为了填满页面而制造推荐。地点、图片、评价、距离、费用、停车、厕所、安全提醒等信息必须尽量来自真实来源。

如果信息无法确认，应该清楚地留空、标记待补充，或显示友好的空状态。

## 2. 信任

推荐必须值得相信。

栖美地面向亲子家庭，错误信息会直接影响出行体验和安全感。每一次推荐都要优先考虑家庭是否能放心决策。

信任来自：

- 真实地点
- 真实图片
- 清楚的适合人群
- 明确的风险提醒
- 不夸张、不诱导、不标题党

## 3. 陪伴

帮助家庭把时间留给家人。

栖美地不是让用户沉迷浏览，而是帮助家庭更快决定这个周末去哪，把更多时间留给路上、草地、溪边和家人。

产品设计要减少选择负担，提高决策效率。

## 4. 长期主义

所有设计服务未来十年。

栖美地的品牌、内容和产品体验不追短期热点。视觉系统要耐看、稳定、可扩展，适合未来网站、社媒、App、小程序和线下活动长期使用。

不要为了短期流量牺牲品牌可信度。
