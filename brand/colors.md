# Colors

栖美地第一版品牌色只允许使用以下颜色。

禁止随意新增品牌色。新增颜色必须先更新 Brand Kit。

## Core Palette

| Token | Color | Usage |
| --- | --- | --- |
| Primary | `#2E7D32` | Main action, brand highlight, positive decision |
| Primary Hover | `#256628` | Hover state for primary action |
| Secondary | `#F5F7F3` | Soft section background, calm surfaces |
| Accent | `#F59E0B` | Important but non-primary emphasis |
| Background | `#FFFFFF` | Main page background |
| Surface | `#FAFAF8` | Cards, subtle panels, light page areas |
| Border | `#E5E7EB` | Dividers, card borders, input borders |
| Text Primary | `#1F2937` | Main text |
| Text Secondary | `#6B7280` | Supporting text |
| Success | `#22C55E` | Success feedback |
| Warning | `#F59E0B` | Warning, attention |
| Danger | `#EF4444` | Error, destructive action |

## Usage Rules

- Primary green is for important actions and brand anchors.
- Accent orange is for limited attention, not decoration everywhere.
- Background and Surface should keep the product quiet and readable.
- Do not use heavy gradients as a default brand treatment.
- Do not use many saturated colors in one module.

## Accessibility

Text on colored backgrounds must remain readable.

Avoid using color alone to communicate important status. Pair color with text labels or icons.
