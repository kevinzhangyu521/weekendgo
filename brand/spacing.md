# Spacing

栖美地使用固定 spacing scale，保证网站、社媒模板和未来 App 有统一节奏。

## Spacing Scale

| Token | Value |
| --- | ---: |
| 1 | 4px |
| 2 | 8px |
| 3 | 12px |
| 4 | 16px |
| 5 | 20px |
| 6 | 24px |
| 8 | 32px |
| 10 | 40px |
| 12 | 48px |
| 16 | 64px |
| 20 | 80px |

## Usage

- 4px / 8px: icon and label micro spacing
- 12px / 16px: form fields, tag groups, compact card spacing
- 20px / 24px: card padding, content groups
- 32px / 40px: section internal spacing
- 48px / 64px / 80px: page section spacing

## Rules

- Do not invent random spacing such as 17px or 29px.
- Use fewer spacing sizes per page.
- Mobile spacing can be tighter, but should still use the same scale.
- Empty states need enough breathing room, but should not look abandoned.
