# Radius

圆角是栖美地温和、亲近感的一部分，但不能过度卡通化。

## Radius Scale

| Element | Radius |
| --- | ---: |
| Button | 12px |
| Card | 16px |
| Image | 20px |
| Input | 12px |
| Modal | 24px |

## Usage Rules

- Buttons should feel friendly and easy to tap.
- Cards should be soft but structured.
- Images can use larger radius to feel warmer.
- Modals can use the largest radius because they are temporary focus surfaces.
- Avoid mixing too many radius values in the same module.

## Do Not

- Do not use fully rounded cards unless the component is intentionally pill-shaped.
- Do not use sharp square images in consumer-facing discovery cards.
- Do not use extreme playful radius for serious safety or decision information.
