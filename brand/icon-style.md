# Icon Style

栖美地图标用于帮助用户快速理解信息，不是纯装饰。

## Style

- Outline
- 2px stroke
- Round join
- Round cap
- Simple geometry
- Consistent optical size

## Recommended Usage

Use icons for:

- 地点
- 距离
- 适合年龄
- 游玩时长
- 预算
- 预约
- 停车
- 卫生间
- 天气
- 安全提醒

## Forbidden

- 实心图标
- 混合风格图标
- 复杂插画图标
- 多套图标库混用
- 表情符号作为核心 UI 图标

## Rules

- Same meaning must use the same icon across the product.
- Icon should appear with text when the meaning may be unclear.
- Icon color should support hierarchy, not create noise.
- Icons in decision cards should be small and readable.
