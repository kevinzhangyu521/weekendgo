# Typography

栖美地的字体系统应清晰、稳重、适合中文阅读。

## Recommended Font Stack

```css
font-family:
  "PingFang SC",
  "HarmonyOS Sans",
  "Noto Sans SC",
  system-ui,
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  sans-serif;
```

## Type Scale

| Style | Size | Weight | Line Height | Letter Spacing | Usage |
| --- | ---: | ---: | ---: | ---: | --- |
| H1 | 40px | 800 | 1.2 | 0 | Page hero title |
| H2 | 32px | 800 | 1.25 | 0 | Section title |
| H3 | 24px | 700 | 1.35 | 0 | Card title, detail block title |
| Body | 16px | 400 | 1.7 | 0 | Main reading text |
| Small | 14px | 400 | 1.6 | 0 | Supporting text |
| Caption | 12px | 500 | 1.5 | 0 | Labels, metadata |
| Button | 15px | 700 | 1.2 | 0 | Button text |

| Style | Mobile Size |
| --- | ---: |

## Rules

- Do not use negative letter spacing.
- Do not make every title oversized.
- Long Chinese paragraphs should use comfortable line height.
- Buttons should be confident, not oversized.
- Use weight hierarchy before adding color.
