# Logo Construction

## Principle

The Qimeide logo must be built on a unified grid.

The grid should protect:

- Proportion
- Clear space
- Optical balance
- Small-size recognition
- Consistent scaling

## Grid

Future logo design should define:

- Base unit
- Icon boundary
- Wordmark boundary
- Clear space
- Minimum size
- Alignment rules

## Clear Space

Logo clear space should be based on a visible unit from the logo itself.

No text, image, button, or border should enter this clear space.

The logo must never feel crowded.

## Proportion

The logo system should include:

- Horizontal logo
- Icon-only mark
- Wordmark usage
- Square icon usage

Each version should maintain consistent visual weight.

## Small Size Recognition

The logo must remain recognizable at:

- 16px favicon
- 32px favicon
- 48px app shortcut
- Mobile header size
- Social avatar size

If details disappear at 16px, the logo is too complex.

## Black and White

The logo must work in:

- Full color
- Single black
- Single white
- Monochrome print

If the logo only works with color, it is not strong enough.

## Technical Requirements

The final logo design must support:

- SVG
- App Icon
- Favicon
- Social avatar
- High-resolution export
- Transparent background

## Do Not

- Do not rely on shadow for recognition.
- Do not rely on gradient for recognition.
- Do not rely on tiny details.
- Do not create a mark that collapses at small sizes.
- Do not use unbalanced spacing between icon and wordmark.
