# Logo Do and Don't

## Do

Use the logo with:

- Clear space
- Minimal surroundings
- Unified proportion
- Consistent color
- Correct scale
- Strong contrast

## Do

Keep:

- Icon and wordmark alignment consistent
- Spacing consistent
- Color usage consistent
- Small-size readability protected
- SVG as the preferred master format

## Do Not

Do not:

- Stretch the logo
- Compress the logo
- Change logo color freely
- Add shadow
- Add stroke
- Add gradient
- Change typeface
- Rotate the logo
- Add outline effects
- Place it on noisy backgrounds
- Put it inside unrelated shapes
- Add decorative elements
- Use partial logo pieces as decoration

## Forbidden Visual Treatments

Do not turn the logo into:

- A cartoon mark
- A travel agency symbol
- A scenic spot badge
- A camping badge
- A mascot
- A seasonal sticker
- A complex illustration

## Color Rule

Use only approved Brand Kit colors.

If a new color is needed, update the Brand Kit first.

## Typography Rule

Do not replace the logo typeface after the final logo is approved.

Do not manually recreate the wordmark with a system font.

## Size Rule

If the logo becomes unclear at small sizes, use the icon-only mark instead of forcing the full logo.

## Quality Rule

Never use a low-resolution logo file in production materials.
