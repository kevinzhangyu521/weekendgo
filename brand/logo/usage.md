# Logo Usage

This document defines how future Qimeide logo assets should be used.

Actual logo files will be created in a later package.

## Logo

Use the full logo when brand recognition matters:

- Website header
- Landing pages
- Official documents
- Social profile cover
- Partnership materials
- Public brand pages

The full logo should have enough clear space and should not be squeezed into dense UI areas.

## Icon

Use the icon-only mark when space is limited:

- Mobile navigation
- App icon
- Favicon
- Social avatar
- Small badges
- Loading state

The icon must remain recognizable without the wordmark.

## Avatar

For social accounts, use the icon-only mark.

Avoid using full Chinese text inside tiny avatars.

The avatar should be readable on:

- WeChat
- Xiaohongshu
- Douyin
- Kuaishou
- Video accounts

## Favicon

Favicon must use the icon-only mark.

Do not include:

- 栖
- 栖美
- 栖美地
- Qimeide wordmark

The browser tab already displays the site title.

## Website

Website header should use:

- Icon + 栖美地 wordmark

The logo should not compete with navigation.

## App

App icon should use:

- Icon-only mark
- No tiny text
- Strong silhouette
- Clear center composition

## Social

Social usage should keep the mark clean and consistent.

Do not create seasonal or campaign-specific logo variations unless a separate campaign system is approved.

## Backgrounds

Logo should work on:

- White
- Light neutral
- Dark solid
- Photography with sufficient contrast

Do not place the logo over busy images without a clear contrast treatment.
