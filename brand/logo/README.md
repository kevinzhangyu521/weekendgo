# Qimeide Logo Creative Brief

This folder defines the logo strategy for 栖美地 (Qimeide).

It does not contain logo artwork.

It does not contain SVG, PNG, icon files, or generated images.

The purpose of this folder is to define the creative rules that every future logo concept must follow.

## Brand

Chinese name: 栖美地

English name: Qimeide

Logo role: A long-term trust mark for family weekend decisions.

## Scope

This directory covers Logo Strategy only:

- Concept direction
- Construction principles
- Usage rules
- Do and do not rules

The next package may begin actual Logo Design, but only after this brief is accepted.

## Required Files

- `concept.md`
- `construction.md`
- `usage.md`
- `dos-and-donts.md`

## Core Rule

The Qimeide logo must feel like a reliable family decision brand, not a travel agency, scenic spot, camping gear brand, or children's playground.

## Output Rule

Do not generate:

- Logo image
- SVG
- PNG
- Favicon
- App icon
- AI image

This package is documentation only.
